# Feature Dictionary

See also `reports/tables/feature_dictionary.csv` (generated by the pipeline).

## Families

| Family | Examples | Primary model |
|--------|----------|---------------|
| Price history | `return_120s`, `mid_return_lag_*` | Yes |
| Static liquidity | spread, range, slope, concentration | Yes |
| Static depth | `log_*_depth_*` | Yes |
| Static imbalance | OBI, WOBI, microprice edge, distances | Yes |
| Dynamic liquidity / imbalance | lag changes, rolling means | Yes |
| Snapshot order-flow proxy | `snapshot_ofi_proxy_*` | Yes |
| Volatility | `volatility_*s` | Yes |
| Trade activity (deduplicated) | `new_trade_count_*` | Default **No** |
| Time | `hour_sin/cos`, `dow_*` | Audited; retained if stable |
| Data-collection metadata | `observation_gap_seconds` | Default **No** |

## Feature sets for incremental value

- **price_only** — returns + volatility
- **static_lob** / **dynamic_lob** / **lob_full**
- **full_no_trade** (primary)
- **full_with_trade**
- **full_no_time**

## Limitations

- Clock windows of 30–60s are often empty given ~69s median gaps; defaults use 120–1200s.
- Snapshot OFI proxies approximate net book changes between observations, not individual orders.
- Trade signatures may under-count identical consecutive genuine trades.
